# StackAudit

StackAudit is a free AI spend audit tool for founders, engineering leads, and finance operators who want to understand whether their team is overpaying for AI tools. Users enter their AI subscriptions, plans, seats, monthly spend, team size, and use case, then receive an instant savings audit with shareable public report links.

## Features

- AI tool spend input form
- Supports ChatGPT, Claude, Cursor, GitHub Copilot, Gemini, OpenAI API, Anthropic API, and Windsurf
- Form state persists across reloads with LocalStorage
- Instant audit result with monthly and annual savings
- Per-tool recommendations with reasoning
- Honest $0 savings state when no clear savings are found
- Supabase lead capture
- Shareable public report URLs
- Public reports strip email/company/personally identifying details
- Honeypot field for basic abuse protection
